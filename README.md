# kap-site
KAP Kedida Auto Part - site et photos des modèles

- `index.html` : le site (une seule page, FR / عربي), repris de l'artifact « KAP Kedida Auto Part »
- `fonts/`, `hero/`, `logos/` : polices, image d'en-tête, logos des marques
- `models/` : photos des modèles (`models/hd/` = vitrine allégée + variantes mobiles `-m`, sources dans `models/hd/src/`)
- `parts/` : photos des pièces détourées (`parts/orig/` = originaux)
- `video/` : éléments pour la vidéo

Aperçu local : `python3 -m http.server` puis ouvrir http://localhost:8000
